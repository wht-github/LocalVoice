修复部分机器上界面不可见的问题：窗口位置和按钮都正常，但悬浮球、面板和设置窗口不显示内容。本版改为纯软件渲染，界面不再经过 OpenGL／Direct3D，也不会因为显卡驱动无法合成窗口而空白。

## 本版变化

- **修复界面不可见**：AMD 显示驱动 2026-10-22 更新后，OpenGL 窗口在本机不再被桌面合成器显示；同一驱动下 Direct3D 12 连设备都创建失败（`Parent device is lost`）。旧版仍能识别和输入，但悬浮球、面板和设置窗口是空白的，点击原位置才有反应。
- **只使用软件渲染**：界面由 softbuffer 在 CPU 上绘制，不依赖显卡驱动；悬浮球圆边保留逐像素透明混合。实测空闲约 0.9% 单核、工作集约 27 MiB，滚动 1120×1280 设置窗口约 0.7% 单核。
- **安装包更小**：不再包含 OpenGL 与 wgpu 渲染栈，客户端 EXE 从 15,373,824 字节降到 14,842,880 字节。
- **移除渲染器开关**：不再读取 `LV_RENDERER` 环境变量；此前为绕过旧问题设置过该变量的用户可以删除。

识别与整理模型、输入方式、快捷键和设置文件格式都没有变化；升级后已有模型和设置直接复用，不需要重新下载。

## 下载与安装

1. 下载下方 **LocalVoice-v0.4.3-windows-x64.zip**（约 18 MB），完整解压到有写入权限的目录。
2. 双击 **Start LocalVoice.cmd**。首次自动准备约 182 MB 的基础组件，完成后启动；无需 Python、Git、Rust 或 PowerShell 7。
3. 将光标放进输入框，用 **Ctrl+Alt+Space** 开始、结束录音。

支持 Windows 10 / 11 x64。模型准备完成后可离线使用。

## 升级提醒

从托盘退出旧版，将新版 ZIP 完整解压覆盖到原目录，**保留整个 `.runtime` 文件夹**，再双击启动。已有模型和设置会复用，本版模型无需重新下载。

此前若为了绕过界面空白设置过 `LV_RENDERER`，可以删除该环境变量；本版不再读取它。
