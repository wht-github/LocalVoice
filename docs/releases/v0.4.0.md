# LocalVoice v0.4.0 — 原生语音输入与笔记

这一版让录音、识别和文字整理直接运行在 Rust 与原生模型库上，安装、使用和打包均不再依赖 Python 环境。

## 主要变化

- 接入 Silero VAD，替代固定音量门限，改善低音量语音与纯噪声的区分。模型约 629 KiB，CPU 单线程；录音工作线程执行推理，避免堵塞音频回调。
- Qwen ASR 由 Rust 直接管理 llama.cpp；SenseVoice 改用 sherpa-onnx INT8。模型进程使用私有回环连接，切换、停止与退出清理本应用的模型。
- 新增原样转写、日常输入和笔记模式。Agentic 轻整理与笔记以完整正文为目标，保留原文；失败、超长或输出截断时回退完整转写。整理模型按需加载，空闲 60 秒卸载。
- 日常输入和笔记均手动结束录音，随后自动输入。笔记对照窗口可在设置中关闭；最近结果仍可查看、复制或重新整理。停顿提交仅作为原样转写的可选项。
- 悬浮球与面板保持置顶且不抢焦点。修复停止操作与排队模型准备任务之间的竞态，取消整理时中断 Agentic。
- 移除可选 TTS 功能；历史 Python 调研和对比脚本仍保留，不参与应用运行。

## 安装与升级

退出旧版托盘程序，更新仓库到此版本后：

```powershell
./install.ps1
./desktop.ps1
```

普通安装下载预编译客户端与模型，不需要 Rust、Python、uv 或 pip。无 NVIDIA 显卡用 `./install.ps1 -CpuOnly`。已有完整模型与设置保留。Agentic 权重仍在设置中主动下载，约 688 MB。

附件 `LocalVoice-v0.4.0-windows-x64.zip` 包含 EXE、4 个原生 DLL、构建提交记录与第三方许可；`SHA256SUMS` 用于校验。请保留仓库布局和 EXE 同目录 DLL。源码开发使用 `./install.ps1 -LocalBuild` 与 `./desktop.ps1 -LocalBuild`。

## 验证与边界

41 项 Rust 单元测试覆盖录音、重采样、取消、完整原文回退和排队任务停止。原生回环使用公开录音验证 SenseVoice → Qwen 0.6B → SenseVoice、Agentic、模型切换及退出；界面检查覆盖模式、笔记开关和长文滚动。

VAD 本机有限样例：2 秒音频的检测耗时约 7–9 ms，首次含运行库初始化的工作集增量约 24 MiB。降低 24 dB 的样例仍能检出人声；降低 36 dB 仍漏检。合成白噪声与工频干扰未触发，这不代表所有真实噪声或自然轻声都已验证。

数字改口、英文术语和长笔记仍可能整理错误。语音模型的运行内存另计，不能将权重文件大小理解为实际内存。详细结构与测量方法见 `docs/native-runtime.md`。

下一阶段优先处理识别失败后的录音重试、主动问题记录和麦克风状态，具体验收条件见 `docs/product-roadmap.md`。
