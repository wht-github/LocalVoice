## 下载后怎么使用

1. 在下方 Assets 下载 **LocalVoice-v0.4.1-windows-x64.zip**（约 18 MB），不要选择 Source code。
2. 完整解压到有写入权限的目录，双击 **Start LocalVoice.cmd**。
3. 首次自动下载并校验约 **182 MB** 的基础组件，完成后启动。把光标放进输入框，用 **Ctrl+Alt+Space** 开始、结束录音。

Windows 10 / 11 x64；无需 Git、Rust、Python、PowerShell 7 或独立显卡。若提示缺少 VC++，请安装 [Microsoft 官方 x64 运行库](https://aka.ms/vc14/vc_redist.x64.exe)。当前包尚未签名。

## 这一版解决了什么

- 修复 v0.4.0 ZIP 仍依赖源码仓库的问题，程序可从独立便携目录定位模型和设置。
- 提供双击启动、模型安装菜单及应用设置中的“安装 / 管理模型”入口。
- 默认仅准备 SenseVoice CPU、Silero VAD 与 CPU 运行库，不再要求新用户先下载两套 Qwen。
- 设置中按需下载约 **688 MB** 的 Agentic 整理模型，日常输入与笔记共用；Qwen 0.6B / 1.7B 在安装菜单中按需选择一套。
- 保持手动结束后自动输入、置顶悬浮球和可关闭的笔记调试窗口。模型准备好后可离线使用。
- README 改为产品首页，补齐功能、下载、首次使用、模型选择和更新说明。

这是安装与分发改进，没有更换识别或整理模型，也不代表术语、数字改口和长笔记质量已经解决。新安装默认原样转写；重要内容仍建议核对原文。

## 更新

从托盘退出旧版，将新 ZIP 完整解压覆盖到原安装目录，**保留整个 .runtime 文件夹**，再双击启动。已有模型与设置会复用。

从旧版源码目录迁移时，将旧仓库的 .runtime 复制到新便携目录，放在 EXE 同级；无需复制源码或 Python 环境。

[完整安装与迁移指南](https://github.com/wht-github/LocalVoice/blob/v0.4.1/install.md) · [产品首页](https://github.com/wht-github/LocalVoice#readme)
