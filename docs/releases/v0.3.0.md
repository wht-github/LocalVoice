# LocalVoice v0.3.0

本版新增 GPU 渲染的悬浮球，统一悬浮球、操作面板与托盘的交互，并修复显示变化后的窗口恢复问题。

- 悬浮球用静止圆点、暖色呼吸和绿色波形区分未收音、麦克风开启中与正在收音；球上没有状态文字，透明抗锯齿让圆边更平滑。
- 单击球打开操作面板，按住拖动调整位置。鼠标离开面板约 1.2 秒后收回原处；有待复制文字时保持展开，也可手动收起。
- 托盘左键找回悬浮球；右键提供显示／隐藏、朗读剪贴板、设置和退出。展开、收起和隐藏不改变录音状态。
- 修复悬停时球内偶发的矩形标题栏，以及悬停移动误触发拖动。
- 加强外接屏拔出、显示区域变化和休眠唤醒后的恢复：恢复原生可见状态、移回可用屏幕并完整重绘，保持置顶且不抢输入焦点。

已有用户先从托盘退出，再执行 `git pull --ff-only`、`./scripts/setup-desktop.ps1`、`./desktop.ps1` 更新客户端。模型和设置保留。首次安装请按 [Windows 安装指南](https://github.com/wht-github/LocalVoice/blob/v0.3.0/install.md) 操作。

`LocalVoice-v0.3.0-windows-x64.zip` 包含 Windows x64 客户端、构建信息和第三方许可；`SHA256SUMS` 提供下载校验。模型与识别运行环境由安装脚本另行安装。

验证覆盖 24 项 Rust 单元测试、100%／150%／200% 缩放的悬浮窗场景、11 项交互检查和 12 个显示变化场景。标题栏重绘及显示恢复像素对照无差异。显示／唤醒测试使用独立窗口与模拟消息，未实际执行 HDMI 插拔或系统休眠；未采集真实麦克风。
