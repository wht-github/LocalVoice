# 本地语音 Windows 客户端

Rust + Slint 原生窗口，使用 FemtoVG / OpenGL GPU 渲染。日常运行不需要 Python、pip、Node.js 或 WebView。Silero VAD 和 SenseVoice 由 Rust 调用 sherpa-onnx / ONNX Runtime；Qwen ASR 与 Agentic 整理使用客户端管理的原生 llama.cpp 子进程。

## 启动

普通用户使用 v0.4.2 独立便携包，见 [安装说明](../install.md)。已发布标签的源码目录可在项目根用 PowerShell 7 执行 `./install.ps1` 安装对应 Release，再用 `./desktop.ps1` 启动；修改源码后使用下方本地构建流程。预编译版安装与运行无需 Rust、C++ 开发工具或 Python。只用 CPU 可在安装时加 `-CpuOnly`。Rust 客户端按已保存设置在后台加载识别模型；重复运行 PowerShell 入口不会重复启动已运行的客户端。直接运行 EXE 时必须保留配套 DLL；便携包另需保留脚本与 `localvoice.portable` 标记。

需要构建当前源码时，安装 Rust MSVC 与 Visual Studio C++ 组件，在项目根目录执行：

```powershell
./install.ps1 -LocalBuild
./desktop.ps1 -LocalBuild
```

`-LocalBuild` 运行 `desktop/target/release/local-voice-desktop.exe`，缺少构建时会明确提示。不带参数启动 `.runtime/desktop` 中的 Release；不要同时运行两个版本。更新前先从托盘退出，安装脚本检测到本项目客户端仍在运行时会停止，不覆盖使用中的 EXE 或 DLL。`install.ps1 -Prebuilt` 是默认预编译安装的兼容写法，不能和 `-LocalBuild` 同用。

依赖版本由 Cargo.lock 固定，源码构建会准备配套原生 DLL；首次构建需要联网。安装会校验复用已有 Qwen 权重与下载包，Agentic 权重及保存设置保持不变。首次从 v0.3.0 升级需要补充原生 SenseVoice INT8 和 Silero VAD；旧 Python 模型不会被删除。`setup-speech.ps1` 可单独准备这两项资源，或用 `-VadOnly` 只准备 VAD。版本升级、CPU 安装与 Agentic 准备见 [安装说明](../install.md)。

开始试用时，保留原有 ASR 选择，用“笔记”口述一段日常内容，在目标输入框手动结束录音；整理完成后自动输入。需要核对时从面板或托盘打开最近结果。也可先用原样转写，切换到日常输入或笔记后，在最近结果点重新整理。无需维护术语表，不需要重新下载本机已有的 Agentic 权重。

## 操作

以下功能已包含在 v0.4.2 发布包中。升级保留已有设置；旧版已开启的“连续输入”偏好也会作用于日常输入，需要整段统一整理时请关闭。新配置仍默认原样转写、手动结束。

- 输出模式：面板可选“原样转写”“日常输入”“笔记”，与设置中的 ASR 模型分开。已有设置保留，新设置默认原样转写；手动日常输入与笔记在结束后识别完整录音、整理并一次输入结束时的目标。日常也可开启连续输入。等待中目标变更则保留供复制。录音开始时固定本次模式和术语，处理中不能切换模型或模式。
- 笔记对照窗口：设置的“口语整理与笔记”提供“笔记完成后显示对照窗口（调试）”，默认关闭。开启后先完成交付，再以不激活方式显示对照窗口；关闭不影响自动输入或手动查看最近结果。
- 可选专名：无需填写即可使用，仅在设置中补充项目特有名称，格式为 `规范写法 | 别名, 别名 | 简短说明`，后两列可省略；清空即可关闭。Qwen ASR 只取规范词作为识别上下文；SenseVoice 不使用识别词表。Agentic 整理阶段不注入词表或做逐词替换。
- 整理模型：未安装时点“下载并准备整理模型”，下载约 688 MB 的 AgenticASR-Refiner Q4_K_M（MigoXV 社区量化，固定版本并校验 SHA256）。已安装会校验复用；日常与笔记共用一份，CPU 4 线程、4096 上下文、0 GPU 层。开始录音时在后台准备已安装的模型，录音期间保持可用，结束后恢复空闲 60 秒释放；设置显示“已安装待用”是正常状态。录音时预热不下载缺失权重、不改变整理协议或输出预算。准备可以用停止模型操作中断。旧版模型工作集约 1.20 GiB，仅供参考；原生版和同时使用 UE 的占用应重新实测。
- 最近结果：从面板或托盘打开，可滚动查看、复制完整原文和整理结果，也可按当前日常／笔记模式重新整理，包括先前的原样转写。重试不录音、不再次输入外部应用；当前选择原样转写时需先切到整理模式。一次完整任务替换最近结果，未交付文字独立保留；退出清空。整理失败时，日常输入和笔记都提示并回退完整原文，沿用相同目标检查后交付。
- 手动听写：点击“开始说话”或按 **Ctrl+Alt+Space**，然后选择目标输入框。点击“结束说话”或再次按快捷键后，识别完整录音并一次输入。也可以先选择输入框再开始。停顿不会提交文字，录音期间切换输入框不会自动结束录音。
- 连续输入：设置中勾选“连续输入”并保存，下次开始说话后生效，适用于原样转写和日常输入。开始前选好输入框；开始时绑定窗口与系统键盘焦点，检测到变化后停止采集，后续结果保留供复制。此检查不能区分所有浏览器页面内的输入控件，等待期间应保持目标不变。原样默认约 700 ms 停顿后识别，日常至少等待 1200 ms，再完整识别和整理这一段；不会逐 token 输入，也不回写前一段。长时间不停顿时约每 25 秒提交一段，边界最多相差一个 32 ms 音频帧。再次点击结束或按说话快捷键停止，剩余声音仍识别；点取消则丢弃未完成内容。新设置默认手动模式。

时间分段不理解跨段改口；如果长表达需要统一衔接，关闭连续输入，手动结束后先合并全部 ASR 分块，再整理一次。笔记始终手动结束，保留保存的连续偏好。超过文字模型完整输出预算时明确保留全部原文，建议缩短一段录音。

- 取消：停止采集，忽略尚未完成的任务结果；已经输入的文字不回删。已经保留的待提交文字仍可复制。
- 启动后显示悬浮球，单击展开操作面板，按住拖动球调整位置。未收音时是静止的三个点；收音时为绿色波形与呼吸光环，波形随音量平滑变化；正在打开麦克风时为暖色呼吸光环。球上不显示文字，黄色提示点表示有待复制文字。
- 悬浮球和展开面板保持在普通应用窗口之上，启动、展开、收起与隐藏恢复使用同一置顶路径；原生窗口层级变化时保持置顶，不抢输入焦点，也不添加轮询。其他同样置顶的窗口、系统安全桌面和独占全屏仍受 Windows 层级规则约束。
- 面板用于开始／结束说话、取消、复制结果和设置。鼠标离开约 1.2 秒后自动收回原处，返回面板会取消收回；有待复制文字时保持展开，也可手动点“收起”。移动位置统一通过拖动球完成；打开设置时先收回面板。展开、收起、隐藏均不改变录音状态。
- 左键单击或双击托盘图标找回悬浮球；右键菜单提供“隐藏桌面入口／显示悬浮球”、设置和退出。隐藏后仍可使用快捷键，托盘提示显示收音状态。拔掉外接屏幕后或休眠唤醒后，显示时会恢复最小化状态、移回当前屏幕工作区并完整重绘，保持置顶且不抢输入焦点。
- 设置可选择 SenseVoice CPU、llama Qwen ASR 0.6B Q8、llama Qwen ASR 1.7B Q8；均在 Windows 本机运行。结束当前听写后更换模型并保存，客户端会重新加载识别模型。原生架构见 [原生运行说明](../docs/native-runtime.md)。
- 设置可修改快捷键、麦克风、输出模式和连续输入偏好；不再要求填写识别地址或端口。
- 启动模型操作按已保存配置加载识别；停止模型操作释放识别和整理模型并取消当前任务。自动启动可单独关闭。窗口隐藏不影响识别，**退出客户端会释放进程内模型并结束自己启动的 llama.cpp 进程**。
- Qwen 和 Agentic 各自使用临时本机回环端口和随机访问密钥，端口由程序选择；这是内部原生进程通信。旧配置中的公共 ASR 地址不参与运行，也不连接旧 Python 服务。

手动模式开始录音不检查、不绑定输入框，结束时立即记录 Windows 当前前台窗口、进程和键盘焦点。连续模式在开始时绑定目标。识别完成后通过 Unicode 键盘输入交付，快捷键未松开时等待松开，期间可以取消。目标发生变化时，结果保留供复制；不会抢回焦点、自动按 Enter 或改写整段内容。已检测到的密码框不自动输入。

手动模式录音期间进行 VAD、缓冲音频和更新音量条；手动结束后才识别。长录音在后台拆为不超过 25 秒的块，优先选低音量边界，全部成功后合并成一份结果交给输入框。分块不删除音频，也不改变手动开始/结束的行为。未结束的录音缓存有容量上限，达到后明确报错，不悄悄提交部分内容。

快捷键只登记指定组合，不记录其他按键。普通权限程序无法向更高权限窗口模拟输入；部分自绘编辑器、终端和浏览器控件可能只能使用复制结果。焦点检查与系统输入不是原子操作，极短时间的焦点切换仍存在系统级竞态。

输入不再依赖 UI Automation 判断“可编辑”或比较控件对象身份，因此未暴露标准辅助功能编辑接口的终端和自绘输入框也会尝试正常键盘输入。UIA 仍用于密码提示。SendInput 成功代表系统接收了按键，不保证每种应用都处理了文字。

## 数据与资源

麦克风只在主动开始后采集。回调只转换单声道音频并放入有界队列；独立录音工作线程进行带低通滤波的 16 kHz 重采样与 Silero VAD。模型约 629 KiB、CPU 单推理线程，在录音期间加载；旧音量门限不再决定语音是否保留。音量仅用于波形显示。

VAD 依据人声概率判断起止，保留约 400 ms 字头和 250 ms 额外字尾，模型自身另有短暂尾静音。手动模式从首次讲话开始保留内部停顿和低概率片段，结束时裁去多余首尾；连续模式才按停顿提交。它不消除录音中的噪声，也不保证所有轻声或极短词都能检出。模型缺失或加载失败会明确报错，不退回音量门限冒充模型。队列拥塞时取消当前录音并提示，避免静默漏字。

识别与整理按顺序处理，同时只运行一个任务；相邻待处理音频可合并为最多 25 秒的一段。连续模式积压音频达到 45 秒或队首等待达到 45 秒时停止继续采集并提示，再处理已接受的内容，包括停止时的尾段。45 秒是停止采集的触发阈值，不截断已接受的音频。切换目标或交付失败同样停止采集，后续文字按顺序保留供复制；不会恢复向旧目标自动输入。

不保存录音和转写历史；待复制文字、最近原文与结果仅在当前进程内。设置和术语写入 `.runtime/settings.json`。PowerShell 安装脚本准备原生库和模型；设置中的明确操作可按需下载、校验整理模型。现有 `.venv` 和 Python 调研脚本可保留，但不在应用的启动、录音、识别、整理或退出路径中使用。隐藏窗口保留识别模型，整理模型仍按 60 秒空闲规则释放。

系统辅助功能在独立线程调用；部分异常应用的辅助功能调用仍可能延迟。

隐藏恢复时请求完整重绘，保留原有显示变化后的位置与表面恢复处理。悬浮球的绘制边缘位于原生圆形点击区域内部，通过透明像素抗锯齿，避免 Windows 对可见圆边的硬裁剪。录音结束先提交尾段，再等待 WASAPI 驱动退出。UI Automation 的连接与事务超时分别设为 300 ms；这不是所有辅助功能操作的总耗时保证，多个调用仍可能累计等待。

分辨率、DPI 或窗口尺寸变化后，在框架完成尺寸更新后的首次绘制中重画完整表面；窗口越出新屏幕工作区时移回可见区域。悬浮窗和设置窗口共用此处理，不添加持续重绘定时器。

设置窗口明确激活并显示在前台，麦克风列表在后台加载。Slint 1.17 的 winit 层跨窗口共用鼠标位置，重返相同坐标时可能漏掉移动事件；客户端给悬浮窗和设置窗分别保存坐标并派发点击，避免重复点击失效。真实鼠标三轮打开/关闭验证见 `outputs/desktop/settings-after.json`。

耗时诊断在 `.runtime/timings.jsonl`，约 512 KiB 后清空续写，只记录录音停止、驱动关闭、队列、原生识别、整理、目标检查和输入等阶段的时间、采样率及音频长度，不保存录音、转写文本或应用名称。用于区分等待发生在录音、模型还是输入目标。

2026-09-06 在本机发布版、窗口显示且未录音时测量：程序文件 13.70 MiB，工作集 31.24 MiB，私有提交内存 8.95 MiB。10 秒采样平均占用一个逻辑处理器的 2.19%，折合本机 16 逻辑处理器总量约 0.14%。这是宿主客户端开销，不包含模型服务，也不是录音时的峰值。完整数据见 `outputs/desktop/window-check.json`。

## 开发验证

维护者发布：提交修改后，在仓库根目录运行 `cargo build --manifest-path desktop/Cargo.toml --release --locked`，再运行 `./scripts/package-desktop.ps1`。产物位于 `outputs/release/v<版本>`，包含 EXE、配套 DLL、构建提交与第三方许可。将 ZIP 和 `SHA256SUMS` 上传到同名 `v<版本>` GitHub Release，并在下载页面保留 README 中的 Made with Slint 徽章。普通用户不执行这些构建步骤。

`cargo test --manifest-path desktop/Cargo.toml --locked` 验证录音分段、长音频保留、抗混叠重采样、PCM、快捷键、词表、原生整理协议、失败保留原文及取消交付。实际模型与资源检查使用下面两个显式入口，需已安装相应模型，不使用 Python。真实质量评测见 [口述评测](../docs/dictation-evaluation.md)。

```powershell
./desktop/target/release/local-voice-desktop.exe --vad-check outputs/native-vad-check.json
./desktop/target/release/local-voice-desktop.exe --native-smoke tests/fixtures/ascend-01219.wav outputs/native-smoke.json
```

`--vad-check` 使用项目已有公开录音，比较原始语音、合成衰减轻声、静音、白噪声和工频噪声，输出模型时间、进程内存及旧 RMS 门限消融结果；同时验证手动模式保留内部停顿、连续模式停顿提交与停止尾段。资源按当前进程统计，后续用例会受到分配复用影响。合成轻声和噪声只用于回归，不代表真实房间、键盘声或自然耳语的准确率。

`--native-smoke` 加载本进程拥有的 SenseVoice → Qwen 0.6B → SenseVoice，使用给定 WAV 验证切换、识别、Agentic 整理及停止释放，输出完整文本和耗时。它需要已准备这两个识别模型与 Agentic，会占用模型资源；不录音、不输入外部应用、不修改保存的设置。未运行的检查不能视为通过。

项目根目录 `./scripts/test-desktop.ps1` 运行发布版的专用输入窗口、原生识别与窗口渲染检查，结果位于 `outputs/desktop`。测试不会录音或播放声音。

另外提供显式验证模式：

- `--dictation-ui-check <directory>`：独立创建面板、设置和结果窗口，检查三种模式、长文滚动、小窗口与失败重试状态并导出 PNG；不启动服务、不采集音频、不注册快捷键、不读写剪贴板。
- `--test-fixture`：创建本程序自己的标准输入框和无 UIA 编辑接口的自绘输入框。
- `--native-check <fixture-pid> <report-path>`：只允许操作该 PID 的专用测试窗口，验证中文/emoji 输入、焦点变化拦截和全局快捷键。
- `--service-check <report-path>`：验证原生 SenseVoice 识别公开样例与输入设备枚举；不采集麦克风。
- `--asr-models-check <wav-path> <report-path>`：验证测试进程内 SenseVoice CPU → Qwen 0.6B → SenseVoice 的实际切换、转写与停止，不录音、不输入文字；不加载日常使用的 Qwen 1.7B。
- `--snapshot <png-path>`：通过 Slint 自身渲染器导出本程序悬浮窗和设置窗口，然后退出；不抓取其他应用屏幕。
- `--restore-check <directory>`：连续隐藏/恢复三次，用本进程窗口的实际表面比较像素，不调用会补绘的 Slint 截图，也不移动鼠标。`--unpatched` 只用于对照旧显示路径。
- `--display-check <directory>`：只向测试进程自己的两个窗口发送 100%／150%／200% DPI 和显示变化消息，分别模拟表面丢失、窗口越界；对比实际表面与完整重绘结果。不会修改系统分辨率、启动模型、录音或输入文字。`--unpatched` 关闭本轮修复，用于对照。测试 200% 设置窗口时，当前屏幕工作区须能容纳该窗口。
- `--floating-check <directory>`：独立窗口验证原生隐藏、最小化、移出屏幕、显示／唤醒消息后的恢复，以及悬浮球尺寸、圆形点击区域、透明抗锯齿、空闲静止与收音动效；检查置顶与不抢焦点并输出 RGBA 与桌面合成截图。不启动服务或采集音频；收音状态由测试模拟。可加 `--dpi 96/144/192` 向测试窗口发送原生 DPI 消息；不要用 `SLINT_SCALE_FACTOR` 替代原生 DPI 切换。`--unpatched` 使用旧托盘显示路径，要求检测到恢复失败。
- `--interaction-check <directory>`：使用生产交互控制器和独立窗口验证默认悬浮球、离开后收回、返回取消收回、屏幕边缘位置恢复、待复制面板保持展开及尺寸变化、隐藏与重复找回。模拟收音和局部指针事件，不启动服务、不操作用户鼠标。`--floating-check` 另包含原生标题栏重绘的像素对照与命中区域检查。
- `--topmost-check <directory>`：用本进程的普通窗口重叠遮挡，检查悬浮球在启动、展开、收起、隐藏恢复及显示／唤醒消息后的真实窗口顺序、置顶样式和焦点保持；尝试取消置顶，并移除保护做消融对照。不启动服务、不操作其他应用。
- `--asr-latency-check <wav-path> <report-path>`：用已知音频测量不同采样率和短／长录音的原生识别路径，不录音。
- `--focus-check <foreground-pid> <report-path>`：只读检查指定前台窗口的编辑器属性，不读取输入内容。
- `--target-click-check <foreground-pid> <report-path>`：点击真实悬浮按钮的诊断模式，禁用录音。脚本 `scripts/check-target-click.ps1` 只点击诊断窗口。

真实麦克风、扬声器和日常应用兼容性需结合实际使用验收，不能用构建或文本回环测试替代。

旧版通过专用窗口的中文和 emoji 输入、焦点变化拦截、全局快捷键、设备枚举与窗口渲染检查；这些历史结果不能代替本次原生版验收。资源与窗口检查入口为 `./scripts/check-desktop-window.ps1`，它要求客户端尚未运行，并在检查后保持窗口打开。
